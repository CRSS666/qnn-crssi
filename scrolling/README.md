# Scrolling News directory

This directory will have `.txt`s of many scrolling news.

'Comments' will be opened with `+==` and closed with
`==+`, so a few can be chosen to not be used, or to
add specific notes to certain segments.

## Why?

This makes *my* life easier when editing QNN, as I'll be
able to simply come here and copy each line in raw text,
instead of having to fight a mess between Google Docs and
Premiere Pro.

This also *may* be used for a scrolling news element in the
non-simple QNN Website on [the CRSSi](https://crssi.cc).
That's half the reason why I 'added' comments to this 'spec'.

## i18n

Somehow, QNN is billingual, so instead of just having a single
English `news.txt`, we'll have `la_ng.txt` (for example, [`en_us.txt`](./en_us.txt)
and [`pt_br.txt`](./pt_br.txt)) so anything that should use
the translated scrolling news will be able to fetch it from here.
